## 这是什么？

**Crypto News CN** 面向中文币圈用户，把主流区块链媒体的快讯汇总成一条时间线：按时间排序、可搜索、可按日期筛选，适合盯盘、复盘、写研报前快速过一遍市场信息。

数据源覆盖常见一线媒体（如 WuBlock、ChainCatcher、BlockBeats 等），标题与正文均可检索。

## 功能亮点

| 能力 | 说明 |
|------|------|
| 实时时间线 | 按发布时间竖向时间轴展示，一眼看到「刚才发生了什么」 |
| 标题 / 正文搜索 | 顶部搜索框，关键词同时匹配标题与正文 |
| 按日筛选 | 日期选择器快速切到某一天的资讯 |

| 分页与刷新 | 10 / 20 / 50 / 100 条可选，显示更新时间与条目区间 |
