## 这是什么？

**Crypto News CN** 面向中文 Web3 / 加密货币用户的资讯聚合站：把多家主流区块链媒体的快讯汇总、按时间排列，并提供搜索与按日筛选，方便交易者、研究员和自媒体快速过市场信息。
